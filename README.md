# The Magic Spring: The Rise

Text-based game "The Magic Spring: The Rise" (Russian: "Магический родник: Становление") by Oleg Mushta (Russian: Олег Мушта), a.k.a. sir Olgerd (Russian: сэр Ольгерд).

The game is in Russian, developed for URQ_DOS, adapted for FireURQ by Windwalker, and adapted for [UrqW](https://github.com/urqw/UrqW) text-based game engine.

This repository contains the source code and other resources of the game. The game is available for launch in the [UrqW engine online catalog](https://urqw.github.io/UrqW/?id=magic_spring).

The game was first published on April 12, 2005.

Interactive fiction identifier (IFID) of the game which is its MD5 hash: 11C6C7687568070273C3C0E6EF2B8BD5

## Description

Вчера ваших товарищей не стало… Вам теперь надо добраться до гор Мэрр, которые простираются на востоке за рекой с таким же названием.
Дюжина Орков застала вашу компанию врасплох: Гувер и Рейнджер не успели даже вытащить мечи из ножен, а некромант Мильцус, создав облако смерти, не сумел остановить десяток топоров, направленных на него…
Только вы смогли спастись…
